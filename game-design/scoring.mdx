All values are provisional — balance is determined through playtesting. The table shows the default values from the
complete `game.rules.scoring.score-deltas` configuration. Deployments can override those values; score history retains
the exact delta applied to each entry.

## Scoring table

| Faction | Scoring trigger | Points |
|---|---|---|
| ⚡ Erasers | Annihilate erased an outcome that was leading its event | +3 |
| | Corrupted card that inverted an opponent's effect | +2 |
| 📜 Prophets | Event resolves exactly as written | +4 |
| | Fulfillment declared and succeeds | +8 |
| | Event resolves differently than written | −2 |
| 🔄 Revisionists | Secret preferred outcome wins this era | +4 |
| | Faction still unidentified at final-era scoring (once per game) | +6 |
| | Successful Mimic contributed to outcome winning | +2 |
| 🧵 Weavers | Event added to an active chain | +2 |
| | Completed chain of 3 links, each from a later era than the one before | +10 |
| | Chain broken by an unresolved chain-conflict paradox | −3 |
| 📣 Activists | Rally-mode declaration's exact outcome wins | +8 |
| | Momentum-mode declaration's exact outcome wins | +4 |
| | Live Expose reveals a qualifying Round-1 Push, Suppress, or Swing signature | +2 |

An Annihilate scores only when its target was still in contention and held the highest probability among the
event's remaining outcomes (a tie for highest counts) before that round's Annihilates took effect. Erasing a trailing
or already-erased outcome scores nothing. Only these scoring Annihilates count toward the Erasers' four-annihilation
win condition.

A cascaded or stalled declaration has no winning outcome in that era and earns no declaration score. A Stall breaks
the Activist's consecutive-era streak. Prophet writing and Fulfillment on that event expire without score or penalty,
and a pending Weaver Thread clears without changing confirmed chain length. A later declaration or Thread on the
carried event is independent. Each fact is recorded and consumed at most once for its game, era, player, and reason.

The `FACTION_UNIDENTIFIED` Revisionist bonus is scored with the final era (era 5), together with that era's other
scores and before its victory check, so it can carry a Revisionist to the 20-point threshold. A game that ends earlier
awards no bonus.

Only public facts that name a faction count. A player is disclosed by an Activist's declaration of record, by an Expose
they played being revealed, or by a Weaver's public pending chain link. Intercept, Trace and Scan results, being the
target of an Expose, round summaries and score changes never disclose anyone. A Revisionist is identified when
disclosed, or by elimination: the factions in play are public, so once all but one of the other players are
disclosed, that last player can work out the Revisionist from their own faction. With three players one disclosure is
enough, with four it takes two, and with five the Revisionist can never be eliminated.

### Cross-faction rules

Some rules apply to every player, regardless of faction:

| Rule | Points |
|---|---|
| A paradox cascades | −2 |

If any player submitted Detonate against a cascading event, each detonator pays the base −2 penalty and every other
player pays −4. Multiple Detonates on the same cascade don't stack the multiplier beyond double. The penalty applies
once per cascaded event, even if it has several paradox findings. If Stabilize clears the event, nobody pays a cascade
penalty for it.

## Win conditions

**Normal:** first player to reach **20 points** wins immediately.

| Faction | Timeline Collapse (3 paradoxes) | Timeline Stabilization (5 eras, no winner) |
|---|---|---|
| ⚡ Erasers | LOSE | LOSE |
| 📜 Prophets | LOSE — need stability | WIN |
| 🔄 Revisionists | LOSE | LOSE |
| 🧵 Weavers | LOSE — need stability | WIN if active chain of 3+ |
| 📣 Activists | WIN only if their current-era declaration targets the collapsing event; its outcome is irrelevant | LOSE |
