## EraEnded 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "cascadedParadoxCount": 0,
  "nextEraNumber": 2
}
```

## WinConditionMet 🌐

```json
{
  "gameId": "uuid",
  "winnerId": "uuid",
  "faction": "WEAVERS",
  "finalScore": 20,
  "winType": "SCORE_THRESHOLD"
}
```

## TimelineCollapsed 🌐

Emitted when the 3rd affected event cascades. Multiple persistent paradox findings on one event count once.

`winners` are every player with the highest total score after that era's scoring, including cascade penalties;
ties share the win. Faction and declarations do not affect the result.

```json
{
  "gameId": "uuid",
  "eraNumber": 3,
  "winners": [{ "playerId": "uuid", "faction": "ERASERS" }],
  "losers":  [{ "playerId": "uuid", "faction": "ACTIVISTS" }]
}
```

## TimelineStabilized 🌐

Emitted when 5 eras complete with no winner.

```json
{
  "gameId": "uuid",
  "winners": [
    { "playerId": "uuid", "faction": "PROPHETS" },
    { "playerId": "uuid", "faction": "WEAVERS", "activeChainLength": 2 }
  ],
  "losers": [{ "playerId": "uuid", "faction": "ERASERS" }]
}
```

`winners` are the Prophets with enough written outcomes resolved as written and the Weavers with a long enough
unbroken chain. `activeChainLength` appears only for a qualifying Weaver and gives that chain's confirmed links. If
nobody qualifies, `winners` are every player with the highest total score.

## GameEnded 🌐

```json
{
  "gameId": "uuid",
  "endReason": "SCORE_THRESHOLD",
  "finalScores": [
    { "playerId": "uuid", "faction": "WEAVERS", "score": 20 },
    { "playerId": "uuid", "faction": "ERASERS", "score": 14 }
  ]
}
```

`endReason`: `SCORE_THRESHOLD`, `TIMELINE_COLLAPSED`, or `TIMELINE_STABILIZED`

`finalScores` is the complete game-end score snapshot: the totals after the last scored era. Finalizing the game
awards no further score.

## FactionRevealed 🌐

Produced after `GameEnded`. Factions become public to all players.

```json
{
  "gameId": "uuid",
  "reveals": [
    { "playerId": "uuid", "faction": "ERASERS" },
    { "playerId": "uuid", "faction": "PROPHETS" }
  ]
}
```
