---
title: "Weaver Chain Events"
description: "Events tracking the Weavers faction chain mechanic"
---

Events produced by `timeline-service` tracking the Weavers faction's chain mechanic. A `THREAD` play names one
not-yet-resolved current-era outcome as the chain's newest link. That link is **pending** until it resolves: it
confirms only if its outcome is drawn as the event's winner, otherwise it clears — and if annihilated it first enters
paradox resolution, where the chain itself is at stake unless Tapestry protected that link.

## ChainLinkThreaded 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "eventId": "uuid",
  "outcomeId": "uuid"
}
```

Emitted when its round closes and an accepted `THREAD` creates a pending link naming a not-yet-resolved current-era
outcome. The favorable probability push resolves with that round's other shifts. The link does not count toward `chainLength` until it confirms.
Only one pending link can be open per chain at a time.

## ThreadRejected 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "eventId": "uuid",
  "outcomeId": "uuid",
  "reason": "ALREADY_LINKED"
}
```

Private rejection of one `THREAD` play: the named coordinate is not a not-yet-resolved current-era outcome, the
chain already has an open pending link, or the coordinate is missing. `eventId`/`outcomeId` are absent when the
submission itself was missing a coordinate. Chain length does not change and the message is never broadcast.

## ChainLinkAdded 🌐

```json
{
  "gameId": "uuid",
  "chainId": "uuid",
  "playerId": "uuid",
  "linkedEventId": "uuid",
  "linkedOutcomeId": "uuid",
  "chainLength": 2,
  "previousLinkEventId": "uuid",
  "eraNumber": 2
}
```

Emitted when a chain's pending link confirms because its named outcome was drawn as its event's winner —
`linkedOutcomeId` is always that winner. `eraNumber` is the confirmed link's era, in which the Weaver scores +2 for the link. Reweave never emits this event.

## ChainLinkInvalidated 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "invalidatedEventId": "uuid",
  "invalidatedOutcomeId": "uuid",
  "chainLength": 2,
  "cause": "RESOLVED_DIFFERENTLY"
}
```

Emitted when a chain's pending link does not confirm: another outcome wins its event (including after a cleared
chain-conflict paradox, since an annihilated outcome can't win), its chain-conflict paradox cascades after Tapestry
protection was consumed against it, Tapestry absorbs an Annihilate against it (only where the absorbing Tapestry rule
is configured), its event Stalls or cascades, or the game ends with it unconfirmed. The pending link clears without a
chain penalty — chain length is unchanged.
The Weaver may `THREAD` again only while the chain and game remain active.

`cause` names which of these happened (optional; always set by the producer from `timeline-event` 7.6.0):
`RESOLVED_DIFFERENTLY` (another outcome won), `NO_WINNER` (the event stalled or cascaded, or the link expired when its
era ended), `CHAIN_CONFLICT_CLEARED` (a chain-conflict paradox on the link cascaded or was cleared after Tapestry
protection was consumed), `ANNIHILATE_ABSORBED` and `GAME_ENDED`. Only `RESOLVED_DIFFERENTLY` is a missed Thread
(`CHAIN_LINK_MISSED`, −1 by default); an absent cause is not a miss.

## ChainCompleted 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 3,
  "chainId": "uuid",
  "playerId": "uuid",
  "links": [
    { "eventId": "uuid", "outcomeId": "uuid", "eraNumber": 1 },
    { "eventId": "uuid", "outcomeId": "uuid", "eraNumber": 2 },
    { "eventId": "uuid", "outcomeId": "uuid", "eraNumber": 3 }
  ]
}
```

Emitted when `chainLength` reaches 3 confirmed links. Triggers Weaver win-condition scoring (+10 pts). Top-level
`eraNumber` is the era of the completing link (the last entry in `links`).

## ChainReAnchored 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "discardedEventId": "uuid",
  "discardedOutcomeId": "uuid",
  "linkedEventId": "uuid",
  "linkedOutcomeId": "uuid",
  "chainLength": 2
}
```

Emitted when a `REWEAVE` moves the chain's pending link to a different live outcome of the current era — its event
not yet resolved, the outcome not annihilated, and the event not already a confirmed link. The link stays pending
and confirms only if its new outcome wins. `chainLength` is the unchanged confirmed length; Reweave never adds a
confirmed link or completes the chain.

## ChainProtectionArmed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid"
}
```

Private confirmation that an accepted `TAPESTRY` armed protection for the chain's pending link for the rest of the
current era. Delivered only to the acting Weaver.

## ChainProtectionConsumed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "protectedEventId": "uuid",
  "protectedOutcomeId": "uuid"
}
```

Private confirmation that armed Tapestry protection was consumed by an Annihilate against the chain's pending link.
The chain can no longer break over that link. By default the link stays pending and the era's paradox check still
raises a chain-conflict paradox for it; if that paradox cascades, only the link clears (`ChainLinkInvalidated`, no
`ChainBroken`). Where the absorbing Tapestry rule is configured, no paradox is raised and the link clears at once.
Either way the annihilated outcome can't win. Delivered only to the acting Weaver.

## ChainBroken 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "paradoxId": "uuid",
  "chainLengthAtBreak": 2
}
```

The Weaver loses −3 pts and must start a new chain from scratch. Emitted when a chain's pending link is annihilated,
no Tapestry protection was consumed against it that era, and the resulting chain-conflict paradox cascades unresolved — the chain's only
reachable break trigger. The chain transitions to `BROKEN` and its saga ends. Top-level `eraNumber` is the era in
which the break happened; `paradoxId` correlates to the triggering paradox.
