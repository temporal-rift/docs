---
title: "Weaver Chain Events"
description: "Events tracking the Weavers faction chain mechanic"
---

Events produced by `timeline-service` tracking the Weavers faction's chain mechanic. A `THREAD` play names one
not-yet-resolved current-era outcome as the chain's newest link. That link is **pending** until it resolves: it
either confirms, clears, or — if annihilated without Tapestry protection — enters paradox resolution.

Links are **connected by era succession**: every link comes from a strictly later era than the link before it, so a
chain holds at most one link per era. The events themselves need no other relationship.

## ChainLinkThreaded 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "eventId": "uuid",
  "outcomeId": "uuid"
}
```

Emitted when an accepted `THREAD` creates a pending link naming a not-yet-resolved current-era outcome. The
favorable probability push applies immediately. The link does not count toward `chainLength` until it confirms.
Only one pending link can be open per chain at a time.

## ThreadRejected 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "eventId": "uuid",
  "outcomeId": "uuid",
  "reason": "EVENT_ALREADY_LINKED"
}
```

Private rejection of one `THREAD` play. Chain length does not change and the message is never broadcast.

| `reason`                  | Cause                                                                          |
|---------------------------|--------------------------------------------------------------------------------|
| `MISSING_COORDINATE`      | The submission named no event or outcome; `eventId`/`outcomeId` are absent     |
| `INVALID_COORDINATE`      | The coordinate is not a live, not-yet-resolved current-era outcome             |
| `ALREADY_PENDING`         | The chain already has an open pending link                                     |
| `EVENT_ALREADY_LINKED`    | The event is already a link in the chain                                       |
| `LINK_ERA_NOT_SUCCESSIVE` | The chain already confirmed a link this era (e.g. Tapestry absorbed an Annihilate) |

## ChainLinkAdded 🌐

```json
{
  "gameId": "uuid",
  "chainId": "uuid",
  "playerId": "uuid",
  "linkedEventId": "uuid",
  "linkedOutcomeId": "uuid",
  "chainLength": 2,
  "previousLinkEventId": "uuid"
}
```

Emitted when a chain's pending link confirms — its named outcome resolved as predicted, an armed Tapestry
protection absorbed an Annihilate against it, or its chain-conflict paradox resolved in the Weaver's favor.

## ChainLinkInvalidated 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "invalidatedEventId": "uuid",
  "invalidatedOutcomeId": "uuid",
  "chainLength": 2
}
```

Emitted when a chain's pending link resolves to a different, non-annihilated outcome than predicted, its event
Stalls, or the game ends with it unconfirmed. The pending link clears without penalty — chain length is unchanged.
The Weaver may `THREAD` again only while the chain and game remain active.

## ChainCompleted 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 3,
  "chainId": "uuid",
  "playerId": "uuid",
  "links": [
    { "eventId": "uuid", "outcomeId": "uuid", "eraNumber": 1 },
    { "eventId": "uuid", "outcomeId": "uuid", "eraNumber": 2 },
    { "eventId": "uuid", "outcomeId": "uuid", "eraNumber": 3 }
  ]
}
```

Emitted when `chainLength` reaches 3 confirmed links. Triggers Weaver win-condition scoring (+10 pts). Each entry's
`eraNumber` is the era its outcome resolved in, strictly increasing across `links`. Top-level `eraNumber` is the era
of the completing link (the last entry in `links`).

## ChainReAnchored 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "discardedEventId": "uuid",
  "discardedOutcomeId": "uuid",
  "linkedEventId": "uuid",
  "linkedOutcomeId": "uuid",
  "chainLength": 2
}
```

Emitted when a `REWEAVE` discards the chain's newest link — pending or confirmed — and replaces it with a
different past outcome that won its event and is not already linked. The replacement keeps the era its outcome
resolved in, which must be later than the era of the link before it. `chainLength` is unchanged; Reweave replaces,
it never grows the chain.

## ChainProtectionArmed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid"
}
```

Private confirmation that an accepted `TAPESTRY` armed protection for the chain's pending link for the rest of the
current era. Delivered only to the acting Weaver.

## ChainProtectionConsumed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "protectedEventId": "uuid",
  "protectedOutcomeId": "uuid"
}
```

Private confirmation that armed Tapestry protection absorbed an Annihilate against the chain's pending link, which
confirms anyway (`ChainLinkAdded`) instead of raising a chain-conflict paradox. Delivered only to the acting
Weaver.

## ChainBroken 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "chainId": "uuid",
  "playerId": "uuid",
  "paradoxId": "uuid",
  "chainLengthAtBreak": 2
}
```

The Weaver loses −3 pts and must start a new chain from scratch. Emitted when a chain's pending link is annihilated
without Tapestry protection and the resulting chain-conflict paradox cascades unresolved — the chain's only
reachable break trigger. The chain transitions to `BROKEN` and its saga ends. Top-level `eraNumber` is the era in
which the break happened; `paradoxId` correlates to the triggering paradox.
