  "eraNumber": 1,
  "eventStates": [{
    "eventId": "uuid",
    "outcomes": [
      { "outcomeId": "uuid", "probability": 45, "isAnnihilated": false, "isSealed": false },

## BandedProbabilityPublished 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "eventStates": [{
    "eventId": "uuid",
    "outcomes": [
      { "outcomeId": "uuid", "band": "HIGH" },
      { "outcomeId": "uuid", "band": "MEDIUM" },
      { "outcomeId": "uuid", "band": "LOW" }
    ]
  }]
}
```

Published to all players after Action Round 2 closes. Bands (`LOW` 0–30%, `MEDIUM` 31–60%, `HIGH` 61–90%) are derived from cumulative probability state of Rounds 1 and 2. Exact values remain private — only `SCAN` card players receive those via `ProbabilityStateCalculated`.

## EraResolutionCompleted 🔒

This is service-coordination data, not a standalone player notification. Timeline emits it exactly once after the
individual `OutcomeApplied` and `ParadoxCascaded` facts for the era. Entries are in the original
`EventsDrawn.events` reveal order, including carried-over events.

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "terminalResolutions": [
    { "eventId": "uuid", "revealIndex": 0, "terminalState": "OUTCOME_APPLIED", "winningOutcomeId": "uuid" },
    { "eventId": "uuid", "revealIndex": 1, "terminalState": "CASCADED" },
    { "eventId": "uuid", "revealIndex": 2, "terminalState": "STALLED" }
  ]
}
```

`revealIndex` and array index match the zero-based position in `EventsDrawn.events`; producers and consumers validate
that every active event appears exactly once in that order. Session uses this ordered set to determine the collapsing
event and durably retain each `CASCADED` event ID for the next `EraStarted` after scoring; scoring uses it to finish
cascaded declarations without waiting for an outcome that cannot arrive.

`STALLED` marks an event delayed by a `Stall` card (GDD §3): like `CASCADED`, it carries no winning outcome and the
event carries into the next era instead of resolving this one. Unlike `CASCADED`, it is not a paradox and does not
count toward timeline collapse.
