Events produced by `game-service` session module.

## LobbyCreated 🌐

```json
{ "lobbyId": "uuid", "hostPlayerId": "uuid", "createdAt": "ISO-8601" }
```

## PlayerJoinedLobby 🌐

```json
{ "lobbyId": "uuid", "playerId": "uuid", "playerName": "string" }
```

`playerName` is the player-chosen display name, 1 to 32 characters.

## PlayerLeftLobby 🌐

```json
{ "lobbyId": "uuid", "playerId": "uuid" }
```

## HostTransferred 🌐

```json
{ "lobbyId": "uuid", "previousHostId": "uuid", "newHostId": "uuid" }
```

Emitted when the host leaves a lobby that still has other players. Always followed by `PlayerLeftLobby` for the previous host in the same transaction.

## LobbyClosed 🌐

```json
{ "lobbyId": "uuid", "gameId": "uuid | null" }
```

Emitted when the lobby is disbanded — either explicitly via `CloseLobby` or implicitly when the host leaves as the sole remaining player. `gameId` is null unless a game was already started.

## FactionsDrawn 🌐

```json
{ "gameId": "uuid", "lobbyId": "uuid", "factions": ["ERASERS", "PROPHETS", "WEAVERS"] }
```

Lists which factions are in play this game. Does not reveal assignments.

## FactionAssigned 🔒

```json
{ "gameId": "uuid", "playerId": "uuid", "faction": "ERASERS" }
```

Produced once per player. The `notification` module delivers each copy only to the assigned player.

## GameStarted 🌐

```json
{
  "gameId": "uuid",
  "lobbyId": "uuid",
  "players": [
    { "playerId": "uuid", "playerName": "Ada" },
    { "playerId": "uuid", "playerName": "Ben" },
    { "playerId": "uuid", "playerName": "Cy" }
  ],
  "totalFactions": 3,
  "deckSize": 30
}
```

`players` is the game's roster in seat order, with the name each player chose in the lobby. Each `playerName` is 1 to 32 characters. Players who left the lobby before the start are not on it.

## GameStartFailed 🌐

```json
{ "gameId": "uuid", "lobbyId": "uuid", "reason": "string" }
```

Emitted when faction assignment fails midway. All already-assigned factions are rolled back and the lobby returns to `WAITING`. `reason` is a human-readable failure description (e.g. `"FACTION_ASSIGNMENT_FAILED"`).

## GameStartCancelled 🌐

```json
{ "gameId": "uuid", "lobbyId": "uuid" }
```

Emitted when a player disconnects during game start steps 1–5. The lobby returns to `WAITING`.

## PlayerDisconnected 🌐

```json
{ "gameId": "uuid", "playerId": "uuid" }
```

Emitted when a player's WebSocket disconnects during an active game. Notifies all remaining players. A reconnect grace timer starts immediately — see [PlayerReconnectSaga](/sagas/special#playerreconnectsaga).

## PlayerAbandoned 🌐

```json
{ "gameId": "uuid", "playerId": "uuid" }
```

Emitted when the reconnect grace timer expires. The player is auto-skipped for remaining rounds. If this was the last remaining player, `EndGameSaga` is triggered.

## EraStarted 🌐

```json
{ "gameId": "uuid", "eraNumber": 1, "carryOverEventIds": [], "playerIds": ["uuid", "uuid", "uuid"] }
```

`carryOverEventIds` is empty on era 1. On subsequent eras it lists the reveal-ordered events carried forward from
either a paradox cascade or a stall.

## EventsDrawn 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "events": [{
    "eventId": "uuid",
    "title": "string",
    "outcomes": [
      { "outcomeId": "uuid", "description": "string", "initialProbability": 33 },
      { "outcomeId": "uuid", "description": "string", "initialProbability": 33 },
      { "outcomeId": "uuid", "description": "string", "initialProbability": 34 }
    ],
    "carryOverState": "FRESH"
  }]
}
```

`carryOverState` is required: `FRESH`, `CASCADED`, or `STALLED`. Carried events retain their last known probability
state rather than being reset to 33/33/34.

## HandDealt 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "selectionExpiresAt": "2026-08-13T20:00:00Z",
  "cards": [
    { "cardInstanceId": "uuid", "cardType": "PUSH", "grade": "II", "dealSlot": 1 },
    { "cardInstanceId": "uuid", "cardType": "SCAN", "grade": "I", "dealSlot": 2 },
    { "cardInstanceId": "uuid", "cardType": "JAM", "grade": "I", "dealSlot": 3 },
    { "cardInstanceId": "uuid", "cardType": "COLLIDE", "grade": "I", "dealSlot": 4 },
    { "cardInstanceId": "uuid", "cardType": "AMPLIFY", "grade": "III", "dealSlot": 5 },
    { "cardInstanceId": "uuid", "cardType": "SUPPRESS", "grade": "II", "dealSlot": 6 },
    { "cardInstanceId": "uuid", "cardType": "TRACE", "grade": "I", "dealSlot": 7 }
  ]
}
```

`cardInstanceId` distinguishes two copies of the same card type in the same hand. `grade` is always present;
single-grade cards carry `I`.

This is the private pending seven-card selection pool, not the action hand. `dealSlot` is the stable deal order and
`selectionExpiresAt` is the authoritative deadline. Stabilize and Detonate never appear here; they are dealt
separately if a Paradox Resolution phase opens.

## HandSelected 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "selectionOrigin": "PLAYER",
  "cards": [
    { "cardInstanceId": "uuid", "cardType": "PUSH", "grade": "II", "dealSlot": 1 },
    { "cardInstanceId": "uuid", "cardType": "SCAN", "grade": "I", "dealSlot": 2 },
    { "cardInstanceId": "uuid", "cardType": "JAM", "grade": "I", "dealSlot": 3 },
    { "cardInstanceId": "uuid", "cardType": "COLLIDE", "grade": "I", "dealSlot": 4 },
    { "cardInstanceId": "uuid", "cardType": "AMPLIFY", "grade": "III", "dealSlot": 5 }
  ]
}
```

The selected five cards become the player's action hand. `selectionOrigin` is `PLAYER` for an accepted choice or
`TIMEOUT_RANDOM` if the window expired. A timeout uniformly chooses one of the 21 possible five-card subsets; it
never ranks cards or favors a deal slot, category, or grade.

## ForesightRevealed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "playerId": "uuid",
  "nextEraNumber": 3,
  "revealedEvents": [
    {
      "catalogEventId": "uuid",
      "title": "string",
      "outcomes": [
        { "catalogOutcomeId": "uuid", "description": "string" }
      ]
    }
  ],
  "emptyReason": null
}
```

Private reveal for the foretelling Prophet. `playerId` is the sole viewer, not the player who caused anything —
the message never identifies any other player. `revealedEvents` previews the next era's freshly-drawn deck slice
in deck order: catalog identities with titles and outcome descriptions, never probabilities or bands. In the final
era there is no next draw, so `revealedEvents` is `[]` with `emptyReason` set. The preview expires at the era
boundary and is never broadcast.
