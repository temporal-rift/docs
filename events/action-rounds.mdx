Events produced during action rounds by `game-service` action module.

## ActionRoundStarted 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "timerSeconds": 60,
  "pendingPlayerIds": ["uuid"]
}
```

## CardPlayed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "cardInstanceId": "uuid",
  "cardType": "SCAN",
  "grade": "II",
  "targetEventIds": ["uuid", "uuid"]
}
```

Stored in full for resolution. **Never forwarded to other players.**

Except for `DECOY`, exactly one target mode is set: scalar `targetEventId`, list `targetEventIds`, scalar
`targetPlayerId`, or list `targetPlayerIds`. A `DECOY` carries no target and populates only `disguiseCategory`, the
category the round summary shows for it; `disguiseCategory` is absent for every other card type. The event list contains
one to three distinct UUIDs and cannot carry scalar, player, or outcome targets. The player-target list contains
one to two distinct player UUIDs and cannot carry any other target mode or outcome targets. `NULLIFY` populates the
player-target list (one entry at grade I, two at grade II); `REDIRECT`, `AMPLIFY`,
`JAM` and `INTERCEPT` target a scalar player; SCAN uses list mode and other event-targeting cards use scalar mode. The
producer resolves card type and grade to enforce SCAN's grade-specific list size and current-era membership.

<Note>
Playing `JAM`, `TRACE`, or `INTERCEPT` is captured in `CardPlayed` like any other card. Jam, Trace, and Intercept have
dedicated private result contracts below; `read-service` projects those results into `myJammedUntilRound` and
`myRevealedIntel` for reconnect-safe state.
</Note>

## PlayerJammed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "jammedUntilRound": 2
}
```

Private reveal for the suppressed player. `playerId` is the sole viewer, not the player who caused the Jam. The
closed payload cannot carry an actor identity. Jam blocks faction specials through `jammedUntilRound` but does not
block cards and never crosses an era boundary.

## InfluenceTraced 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "roundNumber": 1,
  "playerId": "uuid",
  "targetEventId": "uuid",
  "influencerPlayerIds": ["uuid", "uuid"]
}
```

Private reveal for the tracing player. `playerId` is the sole viewer. The message names only the players who
influenced `targetEventId` in the preceding round; it cannot carry card type, direction, outcome, or magnitude.
`influencerPlayerIds: []` is valid when nobody influenced the event.

## HandCardIntercepted 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "targetPlayerId": "uuid",
  "revealedCards": [
    {
      "cardInstanceId": "uuid",
      "cardType": "SWING",
      "grade": "III"
    }
  ]
}
```

Private reveal for the intercepting player. `playerId` is the sole viewer; `targetPlayerId` is the observed player.
`revealedCards` holds 0–2 cards sampled from the target's hand. How many is controlled by the played `INTERCEPT`
card's grade (I = 1, II = 2 — `INTERCEPT` has no grade III), capped by the number of cards in the target's hand, and
each entry's `grade` is that sampled card's own grade. It is `[]` when the target hand was empty. The target is never
told they were intercepted.

## SpecialActionPlayed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "faction": "ERASERS",
  "specialAction": "ANNIHILATE",
  "sourceEventId": null,
  "sourceOutcomeId": null,
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "targetPlayerId": null
}
```

`targetPlayerId` is non-null for player-targeting specials (`CORRUPT`, `EXPOSE`). `JAM` is a `CardType`, not a
`SpecialAction`, so it never appears here; `THREAD` is event-targeting, so it uses `targetEventId`/`targetOutcomeId`
instead — `sourceEventId`/`sourceOutcomeId` stay null for every special.

## SpecialRejected 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "playerId": "uuid",
  "specialAction": "CASCADE",
  "chainId": null,
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "reason": "TARGET_NOT_ERASED"
}
```

Private rejection of a `TAPESTRY`, `REWEAVE`, or `CASCADE` play whose prerequisites weren't met. `chainId` is
populated only for a Weaver chain special; `CASCADE` leaves it null.

A `REWEAVE` is rejected with `NO_ACTIVE_CHAIN`, `ALREADY_USED_THIS_ERA`, `MISSING_COORDINATE`, `NO_PENDING_LINK` (the
chain has no pending link this era), `INVALID_COORDINATE` (the target is not a live current-era outcome, or is the
pending outcome itself), or `TARGET_ALREADY_LINKED` (the target event is already a confirmed link).

A `CASCADE` is decided in its own era, once its event is resolved. The first matching reason applies:
`TARGET_NOT_IN_ERA` when the target event is not part of that era, `TARGET_NOT_ERASED` when the named outcome was
never erased, and `EVENT_NOT_CARRIED` when the event resolved with a winning outcome. It only stays pending when the
event carries into the next era through Stall or a paradox cascade.

## ActivistDeclarationRecorded 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "mode": "RALLY",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid"
}
```

The public projection of a Rally or Momentum declaration of record. The raw `SpecialActionPlayed` remains private.
The declaration is scoped to its `eraNumber`; a `STALLED` terminal result fails it, and a later declaration on the
carried event is independent.

## RoundSummaryPublished 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "actionSummaries": [
    {
      "playerId": "uuid",
      "actionCategory": "PROBABILITY_SHIFTER",
      "actionFamily": "CARD",
      "skipped": false
    }
  ]
}
```

Deliberately minimal — **no targets, no specific card types**. Only category and family visible to all. This preserves the information asymmetry that makes the game interesting.

`actionCategory` is one of `PROBABILITY_SHIFTER`, `INFORMATION`, `DISRUPTION`, `PARADOX`, and is absent for faction
specials and skips. `actionFamily` is `CARD` or `SPECIAL`, and is absent for skips. A Decoy play shows the category
its player declared as a disguise, indistinguishable from a real card of that category.
