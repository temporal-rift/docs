Events produced during action rounds by `game-service` action module.

## ActionRoundStarted 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "timerSeconds": 60,
  "pendingPlayerIds": ["uuid"]
}
```

## CardPlayed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "cardInstanceId": "uuid",
  "cardType": "SCAN",
  "grade": "II",
  "targetEventIds": ["uuid", "uuid"]
}
```

Stored in full for resolution. **Never forwarded to other players.**

Exactly one target mode is set: scalar `targetEventId`, list `targetEventIds`, or `targetPlayerId`. The list contains
one to three distinct UUIDs and cannot carry scalar, player, or outcome targets. `NULLIFY`, `REDIRECT`, `AMPLIFY`,
`JAM` and `INTERCEPT` target a player; SCAN uses list mode and other event-targeting cards use scalar mode. The
producer resolves card type and grade to enforce SCAN's grade-specific list size and current-era membership.

<Note>
Playing `JAM`, `TRACE`, or `INTERCEPT` is captured in `CardPlayed` like any other card. Jam, Trace, and Intercept have
dedicated private result contracts below; `read-service` projects those results into `myJammedUntilRound` and
`myRevealedIntel` for reconnect-safe state.
</Note>

## PlayerJammed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "jammedUntilRound": 2
}
```

Private reveal for the suppressed player. `playerId` is the sole viewer, not the player who caused the Jam. The
closed payload cannot carry an actor identity. Jam blocks faction specials through `jammedUntilRound` but does not
block cards and never crosses an era boundary.

## InfluenceTraced 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "roundNumber": 1,
  "playerId": "uuid",
  "targetEventId": "uuid",
  "influencerPlayerIds": ["uuid", "uuid"]
}
```

Private reveal for the tracing player. `playerId` is the sole viewer. The message names only the players who
influenced `targetEventId` in the preceding round; it cannot carry card type, direction, outcome, or magnitude.
`influencerPlayerIds: []` is valid when nobody influenced the event.

## HandCardIntercepted 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "targetPlayerId": "uuid",
  "revealedCards": [
    {
      "cardInstanceId": "uuid",
      "cardType": "SWING",
      "grade": "III"
    }
  ]
}
```

Private reveal for the intercepting player. `playerId` is the sole viewer; `targetPlayerId` is the observed player.
`revealedCards` holds 0–2 sampled cards (grade I = 1, grade II = 2) and is `[]` when the target hand was empty. The
target is never told they were intercepted.

## SpecialActionPlayed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "faction": "ERASERS",
  "specialAction": "ANNIHILATE",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "targetPlayerId": null
}
```

`targetPlayerId` is non-null for player-targeting specials (`CORRUPT`, `EXPOSE`). `JAM` is a `CardType`, not a
`SpecialAction`, so it never appears here; `UNRAVEL` is event-targeting, so it uses `targetEventId`/`targetOutcomeId`
instead.

## ActivistDeclarationRecorded 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "mode": "RALLY",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid"

```

The public projection of a Rally or Momentum declaration of record. The raw `SpecialActionPlayed` remains private.

## ExposeSignatureRevealed 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 2,
  "activistPlayerId": "uuid",
  "targetPlayerId": "uuid",
  "signature": {
    "type": "SWING",
    "targetEventId": "uuid",
    "sourceOutcomeId": "uuid",
    "targetOutcomeId": "uuid"
  }
}
```

Published at Round 2 close. Only the exposed Round-1 signature is public.

## ExposeBehaviorChanged 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 3,
  "activistPlayerId": "uuid",
  "targetPlayerId": "uuid"
}
```

Published at Round 3 close only when the target changes to a different qualifying signature. It never includes the
Round-3 signature or its target.

## RoundSummaryPublished 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "actionSummaries": [
    {
      "playerId": "uuid",
      "actionCategory": "PROBABILITY_SHIFTER",
      "actionFamily": "CARD",
      "skipped": false
    }
  ]
}
```

Deliberately minimal — **no targets, no specific card types**. Only category and family visible to all. This preserves the information asymmetry that makes the game interesting.
