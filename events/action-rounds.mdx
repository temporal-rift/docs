Events produced during action rounds by `game-service` action module.

## ActionRoundStarted 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "timerSeconds": 60,
  "pendingPlayerIds": ["uuid"]
}
```

## CardPlayed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "cardInstanceId": "uuid",
  "cardType": "PUSH",
  "grade": "II",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "targetPlayerId": null
}
```

Stored in full for resolution. **Never forwarded to other players.**

Exactly one of `targetEventId` / `targetPlayerId` is set, decided by card type. `NULLIFY`, `REDIRECT`, `AMPLIFY`,
`JAM` and `INTERCEPT` target a player; every other card targets an event. `grade` is always present and sets the
card's magnitude or scope.

## PlayerJammed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "jammedUntilRound": 2
}
```

`playerId` is the **suppressed** player, and only they receive it — so their client can disable faction specials
instead of letting a submission fail. It deliberately carries no indication of who played the Jam.

## InfluenceTraced 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "roundNumber": 1,
  "playerId": "uuid",
  "targetEventId": "uuid",
  "influencerPlayerIds": ["uuid", "uuid"]
}
```

The payout for a `TRACE`. `playerId` is the **tracing** player. Names who influenced the event last round and nothing
else — never the card, direction or magnitude. `DECOY` plays do not register. An empty list is valid and means nobody
acted. The traced players are never told.

## HandCardIntercepted 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "targetPlayerId": "uuid",
  "revealedCards": [
    { "cardInstanceId": "uuid", "cardType": "SWING", "grade": "III" }
  ]
}
```

The payout for an `INTERCEPT`. `playerId` is the **intercepting** player. Cards are chosen uniformly at random from the
target's hand at round close; the grade decides how many. Empty when the target's hand was empty. The target is never
told.

## SpecialActionPlayed 🔒

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "faction": "ERASERS",
  "specialAction": "ANNIHILATE",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "targetPlayerId": null
}
```

`targetPlayerId` is non-null for player-targeting specials (`JAM`, `CORRUPT`, `UNRAVEL`, `EXPOSE`).

## ActivistDeclarationRecorded 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "mode": "RALLY",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid"
}
```

The public projection of a Rally or Momentum declaration of record. The raw `SpecialActionPlayed` remains private.

## ExposeSignatureRevealed 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 2,
  "activistPlayerId": "uuid",
  "targetPlayerId": "uuid",
  "signature": {
    "type": "SWING",
    "targetEventId": "uuid",
    "sourceOutcomeId": "uuid",
    "targetOutcomeId": "uuid"
  }
}
```

Published at Round 2 close. Only the exposed Round-1 signature is public.

## ExposeBehaviorChanged 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 3,
  "activistPlayerId": "uuid",
  "targetPlayerId": "uuid"
}
```

Published at Round 3 close only when the target changes to a different qualifying signature. It never includes the
Round-3 signature or its target.

## ActionRoundClosed 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "closedReason": "ALL_SUBMITTED",
  "totalActions": 3
}
```

`closedReason`: `ALL_SUBMITTED` or `TIMER_EXPIRED`

## RoundSummaryPublished 🌐

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "actionSummaries": [
    {
      "playerId": "uuid",
      "actionCategory": "PROBABILITY_SHIFTER",
      "actionFamily": "CARD",
      "skipped": false
    }
  ]
}
```

Deliberately minimal — **no targets, no specific card types**. Only category and family visible to all. This preserves the information asymmetry that makes the game interesting.
