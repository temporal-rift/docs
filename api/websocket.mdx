```
WS /ws/games/{gameId}?token=<jwt>
```

Receive-only per-player stream. All game actions go through REST. On connect the server immediately pushes the current game state snapshot.

## Message format

**Server → client:**
```json
{ "type": "EVENT", "eventType": "ActionRoundStarted", "occurredAt": "ISO-8601", "payload": {} }
```

**Client → server (keepalive only):**
```json
{ "type": "PING" }
```

## Per-player filtering

`read-service` notification module enforces these visibility rules before forwarding events to subscribers. Delivering a private event to the wrong player would expose strategic information and break the game.

| Event | Delivered to |
|---|---|
| `FactionAssigned` | Assigned player only |
| `HandDealt` | Receiving player only |
| `HandSelected` | Receiving player only |
| `CardPlayed` | Nobody |
| `SpecialActionPlayed` | Nobody |
| `ActivistDeclarationRecorded` | All players: declaration mode, event, and outcome |
| `ExposeSignatureRevealed` | All players: exposed Round-1 signature only |
| `ExposeBehaviorChanged` | All players: changed-behaviour result only, never the Round-3 signature |
| `ProbabilityStateCalculated` | Nobody |
| `ProbabilityStateRevealed` | Scanning player only |
| `InfluenceTraced` | Tracing player only |
| `HandCardIntercepted` | Intercepting player only |
| `PlayerJammed` | Suppressed player only |
| `ForesightRevealed` | Foretelling player only |
| `BandedProbabilityPublished` | All players in the game — superseded by `AdjustedBandsPublished` for the same game and era; a client that already applied the correction ignores a late preview |
| `AdjustedBandsPublished` | All players in the game — supersedes `BandedProbabilityPublished`; clients keep the correction for the game and era |
| `ParadoxResolutionCardPlayed` | Nobody |
| `EraResolutionCompleted` | Nobody — private service-coordination barrier |
| `ParadoxCascaded` | All players in the game — identifies the carried event but never includes its exact carry-forward weights |
| `FactionRevealed` | All players |
| Unknown or unsupported events | Nobody |

All other player-visible events are forwarded only when they are explicitly listed as public in the event contract.
There is no fallback that broadcasts an unclassified event.

When a carried event appears in the next era, its public event-draw notification identifies the event and its carry
state but omits exact outcome weights. Public bands remain the only shared probability view; exact state remains
limited to the scanning player's private reveal.

## Private reveals

`ProbabilityStateRevealed` is how `SCAN` pays out in real time — it names a single **viewer**, the scanning player,
and goes to their session alone. It is re-sent at the close of every round for the rest of the era, so the scanning
player's values stay current.

`InfluenceTraced`, `HandCardIntercepted`, `PlayerJammed` and `ForesightRevealed` are also addressed by payload
`playerId` — the tracing, intercepting, suppressed and foretelling player respectively — and are delivered to that
player's session alone, never falling back to broadcast. Reconnect-safe Trace and Intercept results are represented in
the `myRevealedIntel` array, Jam status in `myJammedUntilRound`, and the Foresight preview in `myForesightPreview` until
its era ends. In every case the client learns only its own reveal or suppression and is never told who caused it.

## Reconnection

A reconnecting client opens a new WebSocket connection like any other — the server pushes a current game-state
snapshot immediately, the same as on first connect. This is independent of `game-service`'s `PlayerReconnectSaga`,
which only tracks connection bookkeeping:

1. If the player reconnects within the grace period (30s default), `game-service` marks them reconnected and play
   continues
2. If the grace period expires first, `game-service` marks the player `ABANDONED` and auto-skips them for
   remaining rounds — see [PlayerReconnectSaga](/sagas/special#playerreconnectsaga)
