Action round submission endpoints served by `game-service`.

## Record Activist declaration

```http
POST /api/v1/games/{gameId}/eras/{eraNumber}/declarations
```

During the public declaration window — after event reveal and before private Round 1 submissions — an Activist may use
Rally or eligible Momentum to record one current-era declaration. This consumes the Round-1 special-action slot; it is
not a free declaration action.

```json
{
  "specialAction": "RALLY",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid"
}
```

`specialAction` is `RALLY` or `MOMENTUM`. The target must be an active current-era event and outcome. Momentum requires
the same player's successful declaration in the immediately preceding era.

**Response `202`:**

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "specialAction": "RALLY",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "status": "DECLARED"
}
```

| Error | Code | Condition |
|---|---|---|
| `409` | `409-03` | Declaration window closed |
| `409` | `409-04` | Round-1 special slot or declaration already used |
| `422` | `422-07` | Faction/special mismatch |
| `422` | `422-08` | Momentum not eligible |
| `422` | `422-09` | Target event or outcome is not active in this era |

## Submit action

```http
POST /api/v1/games/{gameId}/eras/{eraNumber}/rounds/{roundNumber}/actions
```

Submit a card or faction special for the current action round. **One submission per player per round.**
`eraNumber` and `roundNumber` are public game coordinates and are validated as stale-state guards.

**Card action:**
```json
{
  "actionType": "CARD",
  "cardInstanceId": "uuid",
  "targetEventId": "uuid",
  "sourceOutcomeId": "uuid",
  "targetOutcomeId": "uuid"
}
```

`sourceOutcomeId` is required when the submitted card resolves as `SWING`. For single-target cards it may be omitted.

`STABILIZE` and `DETONATE` are rejected here because they are reactive paradox-resolution cards. `COLLIDE` remains an
ordinary action-round card.

**Special action:**
```json
{
  "actionType": "SPECIAL",
  "specialAction": "ANNIHILATE",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid",
  "targetPlayerId": null
}
```

`targetPlayerId` is `null` for event-targeting specials. Required for player-targeting specials: `CORRUPT`, `UNRAVEL`, `JAM`, `EXPOSE`.

`RALLY` and `MOMENTUM` are accepted only by the declaration endpoint. `EXPOSE` is valid only in Action Round 2 against
a player whose Round-1 action has a qualifying Push, Suppress, or Swing signature. The generic action request still
requires `targetEventId` and `targetOutcomeId` for Expose; those values are accepted but ignored because Expose targets
only `targetPlayerId`.

**Response `202`:**
```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "roundNumber": 1,
  "playerId": "uuid",
  "status": "SUBMITTED",
  "roundClosed": false
}
```

| Error | Code | Condition |
|---|---|---|
| `404` | `404-01` | Round not found |
| `409` | `409-01` | Round already closed |
| `409` | `409-02` | Player already submitted |
| `409` | `409-05` | Expose already used in this era |
| `422` | `422-01` | Card not in hand |
| `422` | `422-02` | Player is Jammed |
| `422` | `422-03` | Invalid target |
| `422` | `422-04` | Faction required for special action |
| `422` | `422-10` | Card type is not eligible during an action round |

## Submit paradox-resolution card

```http
POST /api/v1/games/{gameId}/eras/{eraNumber}/paradox-resolution/actions
```

Submit the authenticated player's single card while the named era's paradox-resolution phase is open. `eraNumber` is
a stale-state guard. There is no `roundNumber` because paradox resolution begins after the action rounds close.
Eligible cards are `PUSH`, `SUPPRESS`, `STABILIZE`, and `DETONATE`. `COLLIDE` remains action-round-only, and `SWING`
is unavailable because this submission has no source outcome.

```json
{
  "cardInstanceId": "uuid",
  "targetEventId": "uuid",
  "targetOutcomeId": "uuid"
}
```

**Response `202`:**

```json
{
  "gameId": "uuid",
  "eraNumber": 1,
  "playerId": "uuid",
  "status": "SUBMITTED"
}
```

| Error | Code | Condition |
|---|---|---|
| `409` | `409-06` | Paradox-resolution phase is not open for this game and era |
| `409` | `409-07` | Player already submitted during the open phase |
| `422` | `422-01` | Card not in hand |
| `422` | `422-06` | Target event or outcome is outside the current game and era |
| `422` | `422-10` | Card type is not eligible during paradox resolution |


## Get round status

```http
GET /api/v1/games/{gameId}/eras/{eraNumber}/rounds/{roundNumber}/status
```

Shows who has submitted. **Never reveals what was submitted.**

**Response `200`:**
```json
{
  "eraNumber": 1,
  "roundNumber": 1,
  "status": "OPEN",
  "timerRemainingSeconds": 42,
  "submittedCount": 2,
  "totalPlayers": 3,
  "pendingPlayerIds": ["uuid"]
}
```

`status`: `OPEN` or `CLOSED`

| Error | Code | Condition |
|---|---|---|
| `404` | `404-01` | Round not found, or the requesting player is not a participant of the game |
