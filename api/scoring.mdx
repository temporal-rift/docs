Score querying endpoints served by `game-service`.

## Get current scores

```http
GET /api/v1/games/{gameId}/scores
```

Factions are hidden (`null`) until `FactionRevealed` fires at game end.

**Response `200`:**
```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "scores": [
    { "playerId": "uuid", "playerName": "string", "score": 12, "faction": null },
    { "playerId": "uuid", "playerName": "string", "score": 8,  "faction": null }
  ]
}
```

| Error | Code | Condition |
|---|---|---|
| `404` | `404-01` | Game not found |

## Get score history

```http
GET /api/v1/games/{gameId}/scores/history
```

Full era-by-era log of score deltas — every scoring event that contributed to the current totals, in the order it
was applied.

**Response `200`:**
```json
{
  "gameId": "uuid",
  "history": [
    {
      "eraNumber": 1,
      "deltas": [
        { "playerId": "uuid", "pointsDelta": 4, "reason": "EVENT_RESOLVED_AS_WRITTEN" }
      ]
    }
  ]
}
```

| Error | Code | Condition |
|---|---|---|
| `404` | `404-01` | Game not found |
