title: "Scoring API"
description: "Score query endpoints served by game-service"
---


Score querying endpoints served by `game-service`. Both endpoints require authenticated game participation. A
nonparticipant receives the same `404-01` response as an unknown game, without receiving game data.

## Get current scores

```http
GET /api/v1/games/{gameId}/scores
```

Factions are hidden (`null`) until `FactionRevealed` fires at game end.

**Response `200`:**
```json
{
  "gameId": "uuid",
  "eraNumber": 2,
  "scores": [
    { "playerId": "uuid", "playerName": "string", "score": 12, "faction": null },
    { "playerId": "uuid", "playerName": "string", "score": 8,  "faction": null }
  ]
}
```

| Error | Code | Condition |
|---|---|---|
| `404` | `404-01` | Game not found or requester is not a participant |

## Get score history

```http
GET /api/v1/games/{gameId}/scores/history
```

Participant-scoped era-by-era log of score deltas. Before final faction reveal, a participant sees their own entitled
reasons; each opponent's rows within an era are combined into a single per-player net entry that retains the summed
signed delta but omits faction-identifying reasons, so no per-reason magnitude, reason count, or ordering for that
opponent in that era is disclosed. After final reveal, permitted detailed reasons may be present for every
participant, including the reserved era-`0` end-game entry.

Total scores and per-era net changes stay public before reveal as intended clues for win-condition tracking: a
single-reason era's net amount may equal that reason's magnitude, but that is the same total-score-difference
information already visible through current scores, not a reason-level disclosure.

**Response `200`:**
```json
{
  "gameId": "uuid",
  "history": [
    {
      "eraNumber": 1,
      "deltas": [
        { "playerId": "uuid", "pointsDelta": 4, "reason": "EVENT_RESOLVED_AS_WRITTEN" }
      ]
    }
  ]
}
```

| Error | Code | Condition |
|---|---|---|
| `404` | `404-01` | Game not found or requester is not a participant |
